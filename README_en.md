# WikiNotebook

> **An extension of the Wikicrop Agricultural Handbook**

---

## 1. Introduction

This repository contains **WikiNotebook**, an extension of the Wikicrop Agricultural Handbook.

### Basic features

- Extract many different document types and store the extraction locations
- Create articles that include the information locations used
- Generate a mind map from an article
- Upload selected articles so the admin can view them
- Manage sources and outlines

---

## 2. Structure

- **MyNotebook**: frontend extension folder to copy into the Wikicrop directory
- **arginotebook_backend**: FastAPI backend folder for the system
- **HuongDanCaiDat_WikiNotebook.pdf**: document with information and installation instructions

---

## 3. Installation

```bash
git clone https://github.com/HoangPhuc-edward/WikiNotebook.git
```

Please follow the instructions in the attached **HuongDanCaiDat_WikiNotebook.pdf** file.
